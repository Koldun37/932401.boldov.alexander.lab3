Что реализовано
- Flexbox для навигационного меню и карточек объектов наблюдения.
- CSS Grid для сетки с космическими фактами.
- Адаптивная раскладка: на широком экране карточки объектов располагаются по три в ряд, на планшете — по две, на телефоне — по одной. Сетка фактов также перестраивается с трёх колонок до одной.
- Медиазапросы для экранов шириной до 900 и 600 пикселей.
- Звёздный фон на основе псевдоэлементов ::before и ::after, а также отдельные звёзды с CSS-анимацией мерцания.
- Эффект затухания звёзд при наведении на раздел «Проекты».
- Эффекты состояний :hover, :active, :focus и :visited для интерактивных элементов.
- CSS-переменные для основных цветов, шрифта и размеров отступов.
- Семантические HTML-элементы, включая nav, section и article.
- Ограничение переполнения контента по горизонтали и адаптация изображений к ширине экрана.
